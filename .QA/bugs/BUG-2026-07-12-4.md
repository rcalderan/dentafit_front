# BUG-2026-07-12-4: Finalizar locação com pagamento pendente exibe erro JS "Cannot read properties of undefined (reading 'logs')"

## Informações Gerais

- **Data:** 2026-07-12
- **Severidade:** ALTA
- **Componente:** `NewRentalComponent` / `RentalWorkflowService`
- **Rota:** `/rental/new`
- **Autor:** QA Automatizado (Cascade)

## Descrição

Ao tentar finalizar uma locação que possui pagamento pendente, o sistema exibe o erro JavaScript `Cannot read properties of undefined (reading 'logs')` em vez de uma mensagem clara informando que a locação precisa estar quitada antes da finalização.

## Passos para Reproduzir

1. Fazer login como `admin`
2. Acessar **Locações → Novo Contrato** (`/rental/new`)
3. Selecionar um cliente (ex: `111.444.777-35`)
4. Adicionar um item de locação válido (ex: produto legado `260712-1`)
5. Adicionar uma parcela com status **Pendente**
6. Salvar a proposta (botão **Salvar Proposta** + atendente `ADM`)
7. Assinar a proposta (botão **Assinar Proposta** + atendente `ADM` / PIN `1234`)
8. Clicar em **Finalizar Locação**
9. Informar atendente `ADM` e PIN `1234` no modal de finalização

## Comportamento Esperado

- O sistema deve informar que não é possível finalizar enquanto houver pagamento pendente
- Ou, alternativamente, exigir que o pagamento seja quitado antes de permitir a finalização
- Não exibir erro técnico de JavaScript

## Comportamento Atual

- Após confirmar o atendente, a tela exibe: `Cannot read properties of undefined (reading 'logs')`
- A locação não é finalizada

### Query de Validação

```sql
-- Locação criada e assinada, mas ainda com pagamento pendente
SELECT rc.id, rc.legacy_id, rc.status, rc.customer_name
FROM rental_contracts rc
WHERE rc.customer_document = '11144477735'
ORDER BY rc.created_at DESC;

-- Parcela pendente
SELECT rp.installment_number, rp.value, rp.status, rp.payment_date
FROM rental_payments rp
JOIN rental_contracts rc ON rc.id = rp.contract_id
WHERE rc.customer_document = '11144477735'
ORDER BY rp.installment_number;
```

## Contexto Técnico

- **Ambiente:** local
- **Browser:** Puppeteer (Chromium)
- **Backend:** Spring Boot 3.4.1 / Java 21 — localhost:8080
- **Frontend:** Angular 21 — localhost:4200
- **Banco:** PostgreSQL (`rentafit`)

## Impacto

**BLOQUEADOR PARCIAL** — O usuário não consegue finalizar a locação e não recebe uma mensagem compreensível sobre o motivo. O erro técnico prejudica a confiança no sistema.

## Workaround

Quitar manualmente a parcela antes de finalizar, ou realizar a finalização via API direta.

## Correção Sugerida

1. Antes de chamar a finalização, verificar se todas as parcelas estão com status `PAID`
2. Caso haja pagamento pendente, exibir mensagem informativa: "Não é possível finalizar a locação enquanto houver pagamentos pendentes"
3. Tratar a resposta de erro do backend sem acessar propriedades de objeto indefinido (`logs`)

## Status da Correção

**CORRIGIDO em 2026-07-19**. A regra de negócio retorna erro explícito para contrato sem parcela paga, e a UI consome a mensagem normalizada pelo serviço de contratos sem acessar propriedades indefinidas.
